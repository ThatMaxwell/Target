UI takes

Target's interface pieces. The brand move is lock-on: focus brackets snap onto whatever you're about to act on. Hover the tiles and cards. Everything is clickable: open and close tabs, press Ctrl K, flip switches, start a download. Motion stays under 320 ms, uses transform and opacity, and turns off with reduced motion.
