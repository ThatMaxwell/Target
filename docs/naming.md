# Naming

## Decision (2026-11-20): **Tab**
The most-used word in browsing. Mark: a heavy "t" on a browser-tab shape, so the logo's shape becomes every tab in the UI. Concepts are in [logo/](logo/index.html). Cubit was dropped; its cube concepts are in [logo/cubit-archive/](logo/cubit-archive/index.html).

### Round 4 (2026-11-21): longer everyday words, tested as thick badges
Test page: [names/index.html](names/index.html) (every name × 6 heavy fonts; type your own).
No browser found for: **Enter, Return, Escape, Scroll, Refresh, Hello, Anyway, Later, Open**. Home: only small homepage apps. Wander: used by small-web discovery tools, not a browser.

Earlier exploration, kept for reference:

## Direction
Claim a word everyone already says many times a day. **Search** did exactly this (a free, lightweight WebKit browser that launched in October 2026) and still got popular. The only conflict that counts is another **browser** with the name. Other software doesn't matter.

## Criteria
1. A common everyday word, one syllable if possible.
2. No well-known browser already uses it.
3. It works as a sentence: "open it in ___", "download ___", "I use ___".
4. Bonus if it ties to the black cube or to what we stand for.

## Candidates

| Name | Why it works | Browser conflict found |
|---|---|---|
| **Open** | People say it constantly ("open a tab", "open the link"). It also means open source, our ★ value. "Open it in Open." | No browser named Open found |
| **Cube** | The logo *is* the name. Black cube = Cube. | Only small iOS apps that show sites on a 3D cube (Cubify etc.) |
| **Page** | The thing a browser shows. "Load it in Page." | None notable |
| **Window** | What a browser is: a window onto the web. | None notable, but it sounds like part of Windows |
| **Home** | Warm, everyday, "my browser is Home". | Only small homepage apps |
| **Tab** | The most-used word in browsing. | Generic "tab browser" apps |
| Block | Fits the cube | **Block Browser exists** (Web3/crypto). Out |
| Go | Short | **Go Browser exists** (iOS) |

## Pick
1. **Open**: the strongest "Search"-style claim, and it carries the open-source message for free.
2. **Cube**: if the brand should be the logo itself.

Note: a common word is hard to search for at first ("open browser"). Search had the same problem. People will type "Open browser", so the website and store listings should always say the name and "browser" together.
